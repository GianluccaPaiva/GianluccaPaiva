### 💼 [Sistema de Gerência de Investimentos (NexusBank)](https://github.com/GianluccaPaiva/Sistema_Gerencia_Investimentos_NexusTeam)
**Java · POO · Maven · CSV · JSON · UML** &nbsp;·&nbsp; 107 commits

Plataforma de gestão de ativos e carteiras de investimentos em equipe.

- Hierarquia de ativos (ações, FIIs, tesouro, criptomoedas e stocks) modelada com classe abstrata, interfaces e polimorfismo.
- Regras de negócio reais: bloqueio de ativos de alto risco por perfil do investidor (conservador, moderado e arrojado) e restrição de produtos exclusivos para investidores qualificados.
- Importação em lote de investidores, ativos e movimentações via arquivos CSV; exportação do estado da carteira em JSON.
- Hierarquia de exceções personalizadas para entradas inválidas e falhas de leitura de arquivos.
- Documentado com diagrama de classes.

### 📚 [NexusClass Web](https://github.com/GianluccaPaiva/NexusClass) · [Demo online](https://gianluccapaiva.github.io/ProjetoPilotoShadcn/)
**React 19 · TypeScript · Vite · Tailwind CSS 4 · shadcn/ui** &nbsp;·&nbsp; 104 commits

Aplicação web educacional com mural, mensagens, calendário e pesquisa por turmas.

- Componentes reutilizáveis com shadcn/ui, tema claro/escuro, hooks customizados e dados em JSON.
- Deploy automatizado no GitHub Pages e pipeline com GitHub Actions.
- README completo, com instalação passo a passo, estrutura do projeto e solução de problemas comuns.

### 📱 [NexusClass Mobile](https://github.com/GianluccaPaiva/reactNative-expo-tailwind-ts-componentesProntos)
**React Native 0.81 · Expo 54 · TypeScript · NativeWind** &nbsp;·&nbsp; 57 commits

Versão mobile do NexusClass, com telas de mural, calendário, pesquisa, mensagens e suporte.

- Estilização com Tailwind no mobile via NativeWind e componentes reutilizáveis no estilo shadcn.
- Separação entre lógica (hooks) e interface (componentes), com suporte a tema claro/escuro, áudio e vibração.

### 🎙️ [Agy-voice](https://github.com/GianluccaPaiva/Agy-voice)
**Python · faster-whisper · edge-tts · customtkinter · arquitetura em camadas**

Interface de voz para um agente de IA de linha de comando: você fala, o app transcreve localmente, envia o texto ao agente e lê a resposta em voz alta.

- Reconhecimento de fala local com Whisper e síntese de voz com edge-tts, com o áudio processado em memória (sem arquivos temporários).
- Interface desktop com tema escuro, widget compacto, ícone na bandeja do sistema e configurações salvas, além de uma versão para terminal.
- Confirmação por voz ou clique antes de o agente executar comandos ou editar arquivos.
- Arquitetura em camadas com barramento de eventos, que separa o motor de voz da interface.

### 🃏 [HackWar](https://github.com/GianluccaPaiva/hackwar)
**Java · POO · Terminal** &nbsp;·&nbsp; 63 commits

Jogo de cartas por turnos (ataque, defesa e suporte) contra um bot.

- Modelagem com classes de carta, baralho, mão, jogador e bot, mais um motor de regras de dano, energia e vida.
- Validação de entradas sem interromper a execução e replay completo das jogadas gravado em arquivo `.txt`.
